# Sources and data handling

- Stanford Computer Graphics Laboratory, [The Stanford 3D Scanning Repository](https://graphics.stanford.edu/data/3Dscanrep/): Bunny, Dragon, Happy Buddha and Drill. The archive URLs and selected PLY members are in `stanford_scene.py`.
- NVIDIA, [CUDA Programming Guide](https://docs.nvidia.com/cuda/cuda-programming-guide/index.html): threads, projection kernel and atomics.
- CuPy, [Installation](https://docs.cupy.dev/en/stable/install.html) and RawKernel documentation: runtime compilation and host/device arrays.
- Giseop Kim, [CUDA 프로그래밍: Thrust 실습 1편](https://gsk1m.github.io/slam/2023/04/08/thrust-practice-1.html), 2023: teaching motivation.
- Google Colab, [output iframe utilities](https://github.com/googlecolab/colabtools/blob/main/google/colab/output/_util.py).

Stanford archives are **not committed**. First use downloads the selected archive to ignored `rt616_data/`. The loader reads a specific PLY member without extracting archive paths. The original model coordinates are normalized for this exercise and may be deterministically sampled; no claim of sensor realism is made. Model downloads and Python package installation contact their respective upstream hosts.

Original authors retain their rights. Consult Stanford's repository for data-use conditions and attribution; this folder does not relicense the Stanford data or bundled third-party dependencies. `assets/preview.png` is a depth visualization generated by this exercise from Stanford Bunny vertices.

Benchmark JSON and runtime logs stay local unless you explicitly share them. No personal absolute paths, notebook outputs, cached models or virtual environments are included in the public package.
